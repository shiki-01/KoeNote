# KoeNote 使い方

KoeNote は、歌声の音程とタイミングをノート単位で補正する ARA2 対応の VST3 プラグインです。
DAW のクリップに割り当てて使い、編集結果はそのまま DAW の再生・書き出しに反映されます。元の音声は変更しません。

## 1. 動作環境

- Windows 10/11（x64）
- ARA2 対応の DAW（基準は Cakewalk Sonar。REAPER、Studio One、Cubase などは未検証）
- 対象の音声: 単旋律のボーカル（モノラル・ステレオ、44.1〜96 kHz、1 クリップ 10 分程度まで）

## 2. インストール

[GitHub の Releases](https://github.com/shiki-01/KoeNote/releases) から、次のどちらかをダウンロードします。

- **インストーラー**（`KoeNote-<バージョン>-windows-x64-setup.exe`）: 実行すると、`C:\Program Files\Common Files\VST3\KoeNote.vst3` にプラグインを配置します（管理者権限が必要）。
  アンインストールは Windows の「アプリ」から行います。
- **zip**（`KoeNote-<バージョン>-windows-x64.zip`）: 中の `KoeNote.vst3` フォルダを `C:\Program Files\Common Files\VST3\` へコピーします。

配置後、DAW でプラグインを再スキャンします。

- インストーラーは、上書き更新のときに古い `KoeNote.vst3` フォルダを削除してから入れ直します。ニューラル加工のファイルは
  `KoeNote.vst3` の中ではなく `%APPDATA%\KoeNote\neural\` に置いてください（[neural-setup.md](neural-setup.md)）。
- インストーラーには署名がないため、Windows SmartScreen の警告が出ることがあります（「詳細情報」→「実行」）。

## 3. DAW での使い方（Cakewalk Sonar の例）

1. オーディオトラックにボーカルのクリップを置きます。
2. クリップを選び、右クリックのメニューの ARA のコマンド（例: 「Audio Random Access」→「KoeNote」）で割り当てます。
   ARA のプラグインは、トラックの FX ビンではなくクリップに割り当てます。
3. KoeNote の画面が開き、自動で解析が始まります。下部のステータスが「解析済み - N ノート」になると、ノートとピッチ曲線が表示されます。
4. ノートを編集して再生します。編集の直後は、レンダリングが終わるまで直前の音が再生されます（ステータスに「レンダリング中…」）。

## 4. 操作

| 操作 | 内容 |
|---|---|
| ノートを上下にドラッグ | ピッチ移動（スナップ: なし／半音／スケール。スケールはルート音とメジャー／マイナーを選択） |
| Alt を押しながらドラッグ | ノートを時間方向へ移動 |
| ノートの左右の端をドラッグ | ノートの長さ（開始・終了位置）を変更。タイムストレッチで反映（子音部は伸縮を抑えます） |
| ダブルクリック | そのノートの編集をリセット |
| 「分割」ツール（または S キー） | ノートをクリック（マウス位置）で分割 |
| 「結合」ボタン（または J キー） | 選択ノートを直後のノートと結合（複数選択時は選択中のノート同士を結合） |
| 「境界」ツール | 隣り合うノートの境界をドラッグして移動 |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直し |
| Delete | 選択ノートの編集をリセット |
| Ctrl+A / Shift・Ctrl+クリック / ドラッグ | 全選択 / 追加選択 / 範囲選択 |
| ホイール / Shift+ホイール / Ctrl+ホイール | 縦スクロール / 横スクロール / 横ズーム（Ctrl+Shift+ホイールで縦ズーム） |
| 右ボタン（中ボタン）ドラッグ | 表示のパン |
| 右側パネル「ノート」 | 選択ノートのピッチ中心の補正、ビブラート量、ピッチドリフト、遷移の滑らかさ、フォルマントシフト（±600 セント）、フォルマントのピッチ追従、ゲイン、子音のゲイン（ノートの直前）、ブレスのゲイン（ノートの直後） |
| 右側パネル「一括補正」 | ピッチ補正の強さ（半音／スケールへ寄せる）、ビブラートの保持、クオンタイズの強さ（グリッド: 4〜32 分音符、長さを保つ／終了位置も寄せる）。「選択ノートに適用」「全ノートに適用」。「キー・スケールを検出」でスナップのスケールを設定。ホストのテンポがない場合は BPM を入力 |
| 右側パネル「MIDI」 | 「ここからドラッグして DAW へ」で元音源のノートを SMF として渡す（ピッチベンド・編集後のノートも選択可）。「保存…」でファイルへ。「読み込み…」またはウィンドウへのドロップで MIDI を目標として取り込み、ピッチ・タイミングの適用強度を指定して「適用」。対応付けできないノートは「割り当て」ツールで手動で対応付け |
| 定規・再生位置 | 定規のクリック・ドラッグ、または再生位置の赤い縦線のドラッグで、ホストの再生位置を移す（ホストが ARA の再生コントローラーを提供する場合のみ。提供しない場合は線だけが動く） |
| 右側パネル「その他」 | A/B 比較（元の音声で聴く。選択ノートの範囲だけも可）、ガイド（リードボーカル）の背景表示と整列（ガイドはドキュメント内の別のクリップ、またはファイルから選ぶと、同じ解析をしてピアノロールの背景に薄い緑で表示される。「開始位置のずれ」の欄・±10 ms ボタン・ツールバーの「ガイド移動」ツールのドラッグで、背景のガイドの開始位置をずらせる。ノートはそれを見ながら手動で合わせる。「自動で整列（DTW）」は現在のずれから DTW で自動整列するボタン。整列後のノートは背景のガイドに重なる位置になる）、タイミング編集の範囲（ツールバーの「範囲」ツールでピアノロールをドラッグして指定。範囲の外は動かず、範囲の中だけで移動・整列が行われる。範囲の外は暗く表示し、範囲内でタイミングを変えたノートの上辺にオレンジの印が付く。「範囲を解除」で戻す）、ニューラル加工（[neural-setup.md](neural-setup.md)） |
| 定規・グリッド | ホストのテンポがあれば、小節・拍の定規とグリッド線だけを表示（ホストの拍子に従う。拍子の情報がなければ 4/4。6/8 などは八分音符を 1 拍として数える）。テンポがない場合のみ、秒の定規になる（「一括補正」で BPM を入力すると小節・拍になる） |
| ホストでの時間範囲の選択 | DAW で時間範囲を選ぶと、ピアノロールがその範囲を表示する（ホストが範囲を通知する場合） |
| ツールバーの「A/B」 | 元の音声と編集後の音声を即座に切り替えて聴き比べる |
| 「割り当て」ツール | ノートを選び、MIDI の目標（枠線）をクリックして対応付ける |
| 「再解析」 | 編集内容をすべて破棄し、音声を解析し直す |
| 「English」/「日本語」 | UI 言語の切り替え |

ホストによっては、プラグインの画面上のキー入力がホストへ渡ることがあります。その場合は、ツールバーのボタンを使ってください。

## 5. 書き出し（ミックスダウン）

- オフラインの書き出しでは、KoeNote は解析・レンダリング・ニューラル加工が終わるのを待ってから音声を返します。
  ニューラル加工を使っている場合、書き出しに数十秒〜数分余分にかかることがあります（待ち時間は最大 5 分。超えた場合は軽量な方式の結果になります）。
- リアルタイムの書き出し（再生しながら録音する方式）では待たないため、ステータスが「反映済み」になってから書き出してください。
- プロジェクトと素材のサンプルレートが異なっていても再生できますが、同じサンプルレートを推奨します。

## 6. 編集内容の保存

編集内容は DAW のプロジェクトファイルに保存されます（ARA の保存機能）。KoeNote を新しいバージョンに更新しても、
古いバージョンで編集したプロジェクトを開けます。

## 7. 不具合の報告

[GitHub の Issues](https://github.com/shiki-01/KoeNote/issues) に、次の情報を添えて報告してください。

- KoeNote のバージョン、DAW の名前とバージョン、Windows のバージョン
- 素材のサンプルレート・チャンネル数・長さ
- 再現手順と、期待した動作・実際の動作
